# Simple Calculator App 🧮

A basic calculator web app that allows users to perform simple arithmetic operations with a clean and intuitive interface.

## 🚀 Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🧼 Clear/reset function  
- 📱 Responsive design for mobile and desktop  

## 🔧 Tech Stack

- Frontend: HTML, CSS, JavaScript (Vanilla)  

## 🛠️ Installation

1. Clone the repository:
   bash
   git clone https://github.com/LKathiresan/simple-calculator-app.git

2. Navigate to the project folder:
   bash
   cd simple-calculator-app

3. Open `index.html` in your browser or start a local development server.
